# Custom Skills

These skills capture Charlie's default coding preferences in a small, reusable form.

## Skills

- `cr-code-style/` — **Combined coding style guide.** Covers core principles, component system, Tailwind, tRPC backend, and refactor boundaries. Use this as the default for any coding task.
- `cr-pr-create/` — Generate pull request descriptions from diff and optionally create via GitHub CLI
